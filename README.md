# Учёт личных трат

Учебный проект: веб-приложение для учёта личных расходов студента. Серверный рендеринг на Go, без внешних веб-фреймворков.

## Стек

- Go, стандартный `net/http`
- `html/template` — серверный рендеринг HTML
- SQLite через `database/sql`, драйвер `modernc.org/sqlite` (чистый Go, без CGO)
- Material Design 3 — свой CSS, шрифт Roboto и иконки Material Symbols (Google Fonts)
- Сессии на cookie, bcrypt (с этапа 5)

## Структура проекта

- *cmd/app* — **точка входа (main.go)**
- *internal/database* — **открытие SQLite и применение миграций**
- *internal/repository* — **ExpenseRepository, весь SQL-код**
- *internal/handlers* — **HTTP-обработчики**
- *internal/models* — **структуры данных**
- *migrations* — **SQL-скрипты миграций**
- *web/template* — **HTML-шаблоны (layout, components, pages)**
- *web/static* — **CSS, JS**

## Запуск

Из корня проекта: **go run ./cmd/app**

При первом запуске создаётся файл базы **expenses.db** и применяются миграции из папки *migrations*. Применённые миграции записываются в таблицу `schema_migrations` и повторно не выполняются.

## Маршруты трат

- `GET /expenses` — список трат и форма добавления
- `POST /expenses` — добавить трату
- `GET /expenses/{id}/edit`, `POST /expenses/{id}/edit` — редактирование
- `GET /expenses/{id}/delete`, `POST /expenses/{id}/delete` — удаление с подтверждением

## Дополнительно (сверх программы этапа 3)

- Переключение светлой и тёмной темы (кнопка в шапке): палитры Material Design 3, выбор запоминается в `localStorage`, по умолчанию берётся системная тема.
- Анимации в духе Material: ripple-волна из точки нажатия на кнопках и навигации, микро-взаимодействия иконок (поворот, сдвиг стрелки), press-эффекты; при `prefers-reduced-motion` вся декоративная анимация выключается.
- Анимации операций с тратами: при добавлении/сохранении текст кнопки «растворяется» по буквам, взрывается конфетти и появляется галочка «Готово»; новая строка влетает в список с подсветкой, отредактированная — мягко мигает; удаление подтверждается удержанием кнопки (hold-to-delete с заливкой), строка вылетает, а соседние плавно сдвигаются (FLIP). Без JavaScript и при `prefers-reduced-motion` все операции работают обычными формами.
- Фирменный курсор-рука вместо системного (только на сайте): движется за указателем на пружине с перелётом, наклоняется по ходу движения и слегка доворачивается при торможении, чуть увеличивается над кликабельными элементами и сжимается при нажатии. На тач-устройствах, без JavaScript и при `prefers-reduced-motion` остаётся обычный системный курсор.

## Известные ограничения текущей версии

- Суммы хранятся в копейках (`int64`), в форме вводятся в рублях с копейками (`250.50` или `250,50`)
- Путь к базе и порт пока заданы в коде — вынос в `.env` на этапе 8
- При неверных данных формы сервер возвращает 400 без повторного показа формы — будет доработано на этапе 7
- Страницы `/login` и `/register` пока заглушки и убраны из навигации до этапа 5
